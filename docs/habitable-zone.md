# 宜居带示意

默认显示绿色宜居带，可通过“显示宜居带”复选框关闭。选中恒星时显示它的宜居带；选中其他天体时显示最近的适用恒星的宜居带。中心随恒星移动，并随模拟光度变化；模拟恒星半径超过估算内边界时隐藏，避免将区域画在恒星内部。

模型沿用行星评分中的恒星类型和质量对应的相对光照，以 390 游戏距离单位作为参考地球距离，内外边界使用 0.95 和 1.67 倍参考距离，再乘相对光度的平方根。未模拟大气、恒星光谱、多恒星共同作用等因素，因此仅供游戏观察，不能认定行星宜居或存在生命。宜居带的天文学定义与条件可参考 [NASA 宜居带介绍](https://science.nasa.gov/exoplanets/habitable-zone/)和 [NASA 参考边界说明](https://assets.science.nasa.gov/content/dam/science/astro/programs/exep/exopag/announcements-2023/files/NASA_ExEP_Target_List_HWO_Documentation_2023.pdf)。
