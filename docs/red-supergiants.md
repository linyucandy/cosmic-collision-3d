# 红超巨星与红特超巨星

3D 沙盒可创建红超巨星与红特超巨星。默认参考半径分别取太阳半径的 700 和 1400 倍，只用于展示典型巨大尺度；实际恒星的尺寸、温度、质量及演化各不相同。创建时如果天体太大，镜头会自动后退；也可用“天体大小”切换到易观察比例。

红超巨星的例子包括[参宿四](https://science.nasa.gov/universe/what-is-betelgeuse-inside-the-strange-volatile-star/)。大犬座 VY 是经常作为[红特超巨星](https://science.nasa.gov/missions/hubble/hubble-solves-mystery-of-monster-stars-dimming/)介绍的例子，周围有失质量形成的物质。游戏里的光晕和外层效果为示意。

达到 3500 游戏质量单位时，这两类天体沿用项目现有的核心坍缩超新星与黑洞演示。这个数值是游戏阈值，不是实际质量预测；真实恒星的最终命运受初始质量、失质量和其他因素影响，也不一定都会留下黑洞。
