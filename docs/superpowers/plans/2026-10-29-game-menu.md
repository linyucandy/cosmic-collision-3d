# 游戏入口与碰撞修复计划

目标：增加轻量游戏选择首页和作者信息，修复随机星系累积卡顿以及岩石表面没有实际撞击痕迹的问题。

设计决定：沿用 HTML + Three.js，不增加运行依赖。首页使用 CSS 星球插画，提供 3D、2D、随机星系、撞击坑观察场景。作者按用户回复署名“晨晨”。直接进入 3D 默认使用单星系统。

方案：保留两个独立模拟器，通过 index.html 连接；相比合并模拟器，这样能保持双击打开和各自运行。随机星系减少真实物理天体，避免以大量装饰恒星增加二次复杂度。撞击坑在碰撞点转换到本地球面 UV 后绘制到实例独有纹理，不污染共享贴图。

验证：`python -m unittest discover -s tests -v`。浏览器使用本机 Chrome；测试侧注入观察接口，不在游戏暴露调试 API。

执行说明：按用户“制作并提交”授权在当前仓库执行；保留原有未跟踪的文档、截图和分享目录，不加入提交。

验证记录：首次回归测试的三项失败分别对应缺失首页、没有撞击痕迹、旧星系未被清除。进一步回归捕获了 Three.js Texture.clone 仍然共享 Source 的问题，修复为独立 CanvasTexture。人工查看桌面首页、390px 手机首页及撞击坑截图。独立审查发现小行星多面体经度原点与球面相差半圈，补充真实几何 UV 对应像素的回归测试并修正。
