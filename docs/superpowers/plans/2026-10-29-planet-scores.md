# 行星环境指数与冲击波可见性

需求：增加地球相似指数、生命存在指数，解决用户看不到冲击波的问题。沿用现有 HTML 与 Three.js，不新增运行依赖。

设计：两个指数均为 0–100 的游戏模拟评分，不声称检测到生命或给出科学概率。地球相似度比较质量、相对半径、恒星照射对应的模拟温度；生命存在指数以相似度、温度适宜度、撞击热量估算环境潜力。无类地固体表面的天体显示 0 和原因。2D 与 3D 共享计算及展示组件，自动显示行星，可切换观察天体。

可见性：两种模式的冲击波按钮固定右上角，首页直接进入演示。演示模式每 3 秒重新播放特效，切换场景或手动发射后结束自动重播，暂停时不播放。冲击波仍限制并发并正常释放资源。
