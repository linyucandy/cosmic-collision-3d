# 像素小城

目标：制作真正可玩的像素城市经营小游戏，并接入现有游戏广场与首页。沿用原生 Canvas/HTML/JS，直接支持 GitHub Pages、离线运行和手机。

玩法：20×20 等距像素地图，连接市政道路，建设住宅、商店、工厂、公园、太阳能、水塔和诊所。人口受有效住宅、就业、水电与幸福度约束；按月结算收入和维护费，人口里程碑只奖励一次。支持拆除退款、一次低资金援助、暂停/倍速/单月推进、平移缩放、本地自动存档与确认重开。

界面：奶油色管理面板、绿色像素地形、逐块绘制的房屋/树木/道路/车辆，城市状态和发展目标清晰可见。手机保留画布及底部工具，报告可展开。所有图形直接由代码绘制，不加载外部素材。

实现：`pixel-city-engine.js` 独立经济/路网/存档模型；`pixel-city-renderer.js` 绘制和坐标转换；`pixel-city.js` 交互与保存；HTML/CSS 提供响应布局。先用 Node 行为测试验证预算、真实路网、水电、人口、奖励和坏存档，再做浏览器建造/结算/保存/手机操作。最后审查、提交推送并实测线上游戏。
