# 像素垂钓：背包、图鉴、升级与水域

用户已授权增加完整收集与闯关功能，并沿用此前自主实现、提交推送与发布流程。

保留原像素画风、键鼠与触控。七种鱼绘制不同侧面图样，捕获后入背包，图鉴保留累计发现与最大尺寸。图鉴提供生物介绍和来源链接；真实资料与游戏变体分开，营养不虚构数值。

钓具和船只各三级升级，明确展示鱼类/金币成本及实际属性变化。交付普通鱼、稀有鱼换装备，消费不抹去已发现图鉴。四个水域逐步开放，改变鱼群、水流、咬钩窗口与张力；按水域钓获和装备目标通关，一次性奖励，不重复领取。后期稀有与传说目标设保底，避免随机阻断进程。

新增纯进度模型作为 HTML 中独立脚本块，可直接用 Node 读取验证；保持单 HTML 无外部资源启动。背包、图鉴、工坊、水域地图放入可关闭的面板，打开面板暂停模拟，关闭保持原暂停状态。本机自动存档，读取时完整校验，失败明确提示，重开需确认。

实施顺序：先写消费/奖励/解锁/存档模型测试；再实现模型和资料；接入捕获、装备与水域；完成图样和手机面板；浏览器覆盖捕获入包、升级扣除、切换水域、刷新恢复和触控；最后只读代码审查、提交推送和线上验证。
