# 暗物质与引力真空星

“暗物质团”和“暗物质晕”是有质量的扩展分布；它们通过引力影响其他天体，并可被普通天体穿过。紫色点只是人为伪彩示意，并非暗物质发出的可见光。“显示暗物质伪彩分布”只控制显示，不会关闭引力。暗物质的存在有多种引力观测证据，但其微观组成尚未确定。参考 [NASA 暗物质介绍](https://science.nasa.gov/dark-matter/)。

选中星系后点击“给星系添加暗物质晕”，会在其当前位置和速度创建一个独立的暗物质晕；两者分别参与引力，之后可能因相互作用而分离。也可运行“暗物质晕演示”。晕使用简化的平滑质量分布与牛顿式引力，不是完整宇宙学模拟；切换大小模式会改变分布尺度，质量保持不变。

引力真空星（gravastar）是尚未证实的假说天体，一些模型将其描述为真空态核心和物质壳组成的紧致结构。游戏外观、尺寸和碰撞均为示意，不代表发现了此类天体。参考 [引力真空星原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC470711/)。
