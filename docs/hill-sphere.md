# 希尔球

开启“显示希尔球”后，蓝色球体显示天体相对伴星的估算范围；默认也显示最多 24 个其他天体。选中天体的球体默认按计算比例绘制；其他天体缩小至 35% 或更小以防遮挡，选中后可查看具体数值与计算比例。可取消“选中天体的希尔球按计算比例显示”，使用缩小示意。图形只用于显示，不参与引力或碰撞；引力由质量、距离和 G 决定。点击“希尔球演示”可观察行星及附近卫星。

希尔球不是引力的截止线。球外仍然存在该天体的引力，只是其他天体的引力与运动条件也会影响卫星能否稳定绕行。引力随距离减弱，参考 [NASA 引力与力的说明](https://science.nasa.gov/universe/overview/forces/)。

优先选择最近的较重天体作为参考，并以游戏的软化引力及相对速度筛除没有引力束缚的飞掠，避免把遥远的无关天体误当作伴星。选中天体质量小于参考天体的 2% 时，采用 `r ≈ d × (m / (3M))^(1/3)`；质量相近或没有更重参考体时，使用圆形双体系统中面向伴星的 L1 距离估计，并标明不是标准希尔半径。没有合适伴星时无法计算；虫洞、白洞的特殊规则也不适用此估算。

其中 `m` 是选中天体质量、`M` 是参考天体质量、`d` 是两者的瞬时距离。这个模型以距离近似圆轨道半长轴，质量和距离均为游戏单位；它不是严格的引力边界，也不保证球内卫星长期稳定。偏心轨道、其他天体、运动速度和方向都可能改变稳定性，模拟中的引力软化也使结果并非真实轨道预测。

公式形式可参考 [NASA 收录的希尔半径示例](https://ntrs.nasa.gov/api/citations/20140011355/downloads/20140011355.pdf)，卫星轨道稳定性还与轨道方向等条件有关，参见 [NASA 收录的卫星稳定性研究](https://ntrs.nasa.gov/citations/19790035284)。
