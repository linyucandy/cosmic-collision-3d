# 希尔球

选中一个天体后，开启“显示希尔球”，画面会以蓝色球体显示它相对于最近较重天体的近似希尔半径；可关闭显示。点击“希尔球演示”可观察一颗绕恒星运行的行星及其附近卫星。参考天体被移除时，显示会重新寻找符合条件的天体；找不到时隐藏。

游戏采用 `r ≈ d × (m / (3M))^(1/3)`，其中 `m` 是选中天体质量、`M` 是参考天体质量、`d` 是两者的瞬时距离。这个公式以距离近似圆轨道半长轴，质量和距离均为游戏单位；它不是严格的引力边界，也不保证球内卫星长期稳定。偏心轨道、其他天体、运动速度和方向都可能改变稳定性，模拟中的引力软化也使结果并非真实轨道预测。

公式形式可参考 [NASA 收录的希尔半径示例](https://ntrs.nasa.gov/api/citations/20140011355/downloads/20140011355.pdf)，卫星轨道稳定性还与轨道方向等条件有关，参见 [NASA 收录的卫星稳定性研究](https://ntrs.nasa.gov/citations/19790035284)。
