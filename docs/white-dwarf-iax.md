# 彩色白矮星与 Iax 型超新星

白矮星面板提供图片中的八个示例。选择彩色圆点，再点击场景即可创建对应样例。颜色和温度来自图片及相关资料，颜色是根据光谱与视觉模型计算的近似示意，并非近距离拍摄照片。DA、DC、DQ 和 DZ 表示不同的光谱特征；DQ 和 DZ 的宽吸收带可能使颜色偏离温度决定的普通恒星颜色。参考：[白矮星颜色研究](https://doi.org/10.1093/rasti/rzag069)、[WD J1147−7457 观测研究](https://academic.oup.com/mnras/article/518/2/3055/6825506)。

点击“Iax 型超新星演示”可看到示意爆发；也可以选中现有白矮星，在面板点击对应按钮触发。该演示采用一种可能的部分爆发模型：抛出部分质量，留下受损的白矮星。质量比例和爆炸外观是游戏设定，并非观测测量，也不代表所有 Iax 事件都有相同的残骸。参考：[NASA 对 Iax 与白矮星残骸的介绍](https://astrobiology.nasa.gov/news/of-white-dwarfs-zombie-stars-and-supernovae-explosions/)。
