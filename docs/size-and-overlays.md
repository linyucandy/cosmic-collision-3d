# 本体、光晕与脉动

新增的暗物质、暗物质晕、引力真空星按钮位于控制面板顶部，手机折叠其他控制后仍可使用。点击按钮，再在画布空白处点击或拖动即可创建。引力真空星的“重力真空星”别名显示在按钮提示中。

普通孤立天体的质量和本体半径不会因希尔球或宜居带显示而变化。光晕是增强观察的显示效果，普通恒星的光晕可能周期变化。造父变星还会按游戏设定周期改变本体半径和光度；其脉动从自身创建时开始，避免沿用场景时间造成第一帧突然跳变。选中后会显示“周期脉动中”。取消“恒星脉动与光晕变化”可暂停脉动，并将造父变星恢复至基准半径，质量不变。

碰撞、吸积、潮汐剥离、强烈自转或高温仍可能改变天体质量。选中后的观察栏显示模拟半径与体积，可用来区分真实尺寸变化和光晕变化。
