# 白洞沙盒示意

白洞是广义相对论中某些黑洞解时间反演的理论概念，尚无确认的观测证据。参考 [NASA 对白洞的说明](https://imagine.gsfc.nasa.gov/ask_astro/black_holes.html)和[美国物理学会相关研究介绍](https://physics.aps.org/articles/v11/127)。

在 3D 沙盒选择“白洞”即可创建，或点击“白洞排斥演示”。演示会切换至“易观察”大小，并创建接近白洞的行星。白洞周围的发光环、一定范围内的向外推力，以及碰撞时将天体弹开的规则都是为了直观体验而设计的游戏效果；较远距离沿用普通引力，不代表已确认的白洞物理。尺寸也仅是参照同质量黑洞视界制作的游戏比例。
