# 两个独立 Canvas 页面的优化

保留原有画风与核心玩法，无框架、无额外网络资源依赖。两个页面分别保留原文件名，并接入首页与游戏广场。

## Cosmos Lab

初始312天体的星系场景，原碰撞循环仍遍历48,516对，再逐项排除粒子之间的碰撞。按既有质量排序，在后续天体均低于可碰撞质量阈值时结束外层循环，初始场景只需621次配对检查，保持原有合并语义。四档透明度批量绘制轨迹，避免每个线段单独stroke；静态星云背景只在尺寸变化时绘制缓存。

调整窗口保持世界视角；重复尺寸通知不重建画布。天体上限600，特效粒子及冲击环设上限。活动指针统一捕获/释放，第二指针不覆盖当前操作，失焦取消拖动。切后台不继续推进模拟。

## 像素垂钓

修复失焦后移动/收线状态卡住、触控无法收线、暂停按钮保留焦点后键盘失效等问题。保留右键收线，增加E键与按住式触控收线。方向按钮支持多指组合，松手、取消和失焦统一释放。暂停不丢失当前钓鱼阶段，切出窗口自动暂停。

画布按显示比例和DPR调整，DPR封顶2，竖屏使用540宽、最高860高的逻辑视口。背景渐变复用，暂停时不反复重绘静止画面，DOM状态仅在阶段变化时更新。抛竿终点限制在湖面范围内。粒子生成概率按时间而非帧数计算。

## 验证

`tests/test_canvas_games.py` 检查碰撞配对预算、质量/动量守恒、视角、数量上限、轨迹绘制预算、多指针、失焦清理、键盘收线与奖励只结算一次、暂停后键盘操作、触控和湖面边界。真实手机触控事件另验证移动、抛竿与刺鱼，并检查桌面和手机截图。社区测试检查独立入口和评分归属。
