# 像素小城：区域都市群

地图为 **96×96，共 9,216 格**，面积是旧版 32×32 的九倍。原五个城区保持原坐标，外围新增八片各有 1,024 格的大区：丰收平原、高地牧场、湖畔新城、中央商务区、科创新城、森林公园区、港湾贸易区和远景新区。

## 探索和扩建

- 点击右下角“区域总览”，查看每区面积、特色、开放条件和价格。“查看”可以预览尚未开放的土地。
- 点击小地图移动视角；地图仍支持缩放、移动工具、右键平移。“居中”回到原市政厅。
- 新区域从第 5–7 阶段逐步开放，并要求先开放至少一个相邻区域。取得土地后，需要铺路接入市政厅；跨水面使用桥梁。
- 完成原有七个阶段后，城市报告自动显示新的五个都市群计划；区域总览也可查看、领取计划奖励。

## 大城市的建设选择

| 建筑 | 实际作用 |
| --- | --- |
| 桥梁 | 在水面延伸市政道路，拆除后保留水面 |
| 公交站 | 覆盖 6 格内住宅，提高幸福度与人口增长 |
| 地铁货运枢纽 | 覆盖 12 格内住宅；跨区线路两端都有枢纽时运力上限为 60 份/月 |
| 大型光伏园、城市水库 | 每座提供 256 单位电力或供水 |
| 住宅组团、商务中心 | 分别提供 120 人住所、90 个岗位 |
| 酒店、博物馆、度假村 | 酒店提供接待容量，景点提供吸引力，实际游客每人每月带来 3 城币旅游收入 |
| 恒温温室 | 每月固定生产 8 份蔬菜，冬季也能保持产量 |
| 国际贸易港 | 本地商场售卖后，出口剩余商品，出口价为零售价的 80% 向下取整 |

丰收平原的粮田与蔬菜农场每座额外产出 2 份；高地牧场的奶牛牧场、养鸡场每座额外产出 1 份；中央商务区的商场每座销售能力为 18 份；科创新城的科技园增加产业收入；森林区度假村吸引力提高 50%；港湾贸易港每座出口能力为 40 份，其他地区为 24 份。

所有设施都需要接入市政道路，生产、交通和旅游效果受水电供应影响。旅游人数由接待容量、吸引力、幸福度和水电共同决定。人口较大的城市拥有更快的自然移民速度，交通覆盖会进一步改善增长。

## 五个都市群计划

1. **区域开拓者**：800 人、丰收平原与湖畔建设、公交服务。
2. **都市交通网**：1,200 人、高地与商务区、轨道枢纽和就业。
3. **生态旅游名城**：1,600 人、森林酒店与文化景点、100 位游客。
4. **港湾贸易圈**：2,400 人、科创与港湾、累计出口和就业。
5. **未来都市群**：4,000 人、全部十三片区域、新区建设、交通覆盖与长期经营盈余。

每步的具体指标会实时显示。已验证能从正常 900 城币开局，依靠真实建造、经营收入和人口增长完成全部计划。

## 存档和性能

v1 的 20×20 城市与 v2 的 32×32 城市会逐格迁移到 v3 世界，保留原坐标、资金、人口、阶段、项目、库存和商业线路。新区域开始时尚未开放，库存为空。继续使用原浏览器即可接续。

界面在建造、结算或开放区域后更新城市计算；动画与地图悬停复用计算结果。绘制会跳过屏幕外土地，缩小时使用简化总览，小地图底图只在城市变化时更新。
