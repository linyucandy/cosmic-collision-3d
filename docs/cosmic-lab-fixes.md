2026-10-30，保留独立 HTML 入口，与原宇宙模拟器分别发布。

## 已复现并修复

- 导出保存的是物理半径，导入又按质量缩放：导入改为直接使用已校验的物理半径。
- 导入失败先清空场景、允许任意对象字段及名称 HTML：先完整校验版本、数量、数值、向量、类型和长度，再替换场景；名称只作为文本显示。取消选择或错误文件保留原场景。
- 碎裂把总质量 7 变成 5.53，且计算速度前已改写质量：先记录总动量，再分配残留体与碎片质量，用零均值碎片速度偏移保持总动量。
- 高速球体只检查终点，可能穿透：计算每子步相对运动路径中的最早接触时间，再响应碰撞和剩余运动。接触响应后重新计算剩余时间内的接触，支持连锁碰撞；达到单步事件预算时保留位置至下一步，仍是可视化近似模型。
- 连续拖动沿用旧偏移、右键缺少指针捕获：每次重新计算偏移，统一捕获并校验活动指针，取消/失焦时清理状态。
- 名称和参考线开关没有功能：实现投影名称和可隐藏的示意环，明确参考环不是预测轨道。
- 重置遗留特效、子网格及轨迹材质：统一清理；轨迹使用固定 90 点缓冲，更新包围球，避免反复分配及错误裁剪。
- 每帧重建对象列表：仅在结构或选中项变化时重建，并节流状态刷新；天体数量限制为 100。
- 外部 CDN 是启动依赖：Three.js r160 与 MIT 许可证随站点提供。
