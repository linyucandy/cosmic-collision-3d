# 特殊天体与钱德拉塞卡极限

3D 沙盒的“特殊与假想天体”菜单包含观测到的对象和理论模型。外观、颜色、周期、质量和尺度均为便于游戏的示意；真实世界中这些天体的大小和成分并没有统一的游戏数值。

| 名称 | 科学状态与游戏表现 |
| --- | --- |
| 樱井天体 | 已观测的 V4334 Sgr，经历了极晚期热脉冲并形成尘埃。游戏呈现一颗有尘埃包层的再生恒星。 |
| 造父变星 | 已观测的脉动恒星。游戏加快了周期，让半径和亮度变化可见；周期不是实测值。 |
| 类星体 | 已观测的明亮活动星系核，其能量来自中央超大质量黑洞周围的吸积。游戏将吸积盘、喷流及透镜作为示意；并非所有类星体都有明显喷流。 |
| 奇异星 | 尚未确认的致密星模型，与奇异夸克物质和夸克星有关。 |
| 电弱星、先子星 | 尚未确认的假说；先子的存在本身也未得到实验证实。 |
| 玻色子星、孤子星、Q 星 | 理论模型，彼此有概念和模型重叠，并非已观测的独立天体类别。 |
| 黑矮星 | 白矮星在极长时间冷却后的理论状态；目前宇宙年龄不足以形成这样的天体。游戏中仅供手动创建，不会按真实时间自动产生。 |
| 黑中子星 | “黑中子星”没有统一、已确认的标准天体分类；游戏将其作为冷暗致密星的想象设定。质量间隙中的真实观测对象也不因此被确定为这一类别。 |

## 钱德拉塞卡极限

钱德拉塞卡极限约为 1.4 倍太阳质量。白矮星的实际命运还取决于成分、吸积、自转等条件，并非所有达到这个近似值的白矮星都会发生同一种爆发。

沙盒采用单独的白矮星演示换算：**3000 游戏质量单位对应 1 太阳质量，4200 对应约 1.4 太阳质量**。达到 4200 时，游戏将其按碳氧白矮星的简化情景演示为 Ia 型超新星；这不代表其他天体的游戏质量都能按同一比例转换。在“特殊与假想天体”中点击“钱德拉塞卡极限演示”，再点击“继续”可以观看。

参考大小模式下，一些假想致密星极小，会显示定位圈；可切换“易观察（旧比例）”查看示意外观。游戏没有求解未知的微观物质状态或完整的广义相对论。
