# 星系沙盒

3D 天体列表提供旋涡、椭圆和不规则星系，可点击或拖动放置；“星系碰撞演示”创建两个相互接近的旋涡星系。保留原有“随机星系”场景，它由可单独模拟的天体组成。

新增星系各自是一个参与引力和碰撞的整体，内部星点是装饰性渲染，并非独立恒星。星系盘接近或重叠时，画面会示意潮汐拉伸；核心接近后才整体合并，并以加速过渡显示残骸趋于稳定。质量相近的两个星系在游戏中产生椭圆星系；质量相差较大时保留较大星系的类型。真实星系的相遇结果取决于轨道、结构和其他因素。为控制性能，每帧最多对 32 个星系进行潮汐变形。

星系整体与单颗天体不会因为范围重叠就合并，但仍然参与简化引力运算；这避免把稀疏星系当作会吞没天体的实心球。

游戏大小、质量、拉伸和时间不是实际单位，不能用于研究真实星系碰撞或恒星轨道。参考 [NASA 对星系碰撞的说明](https://science.nasa.gov/missions/hubble/hubbles-dazzling-display-of-2-colliding-galaxies/)及[星系类型介绍](https://science.nasa.gov/universe/galaxies/types/)。

默认星系参考半径为 700 万游戏单位，比默认红特超巨星大 100 倍以上；为兼顾游戏操作，仍未按真实天文尺度呈现。切换“易观察”比例会缩小场景中的天体，同时保持星系明显大于恒星。
